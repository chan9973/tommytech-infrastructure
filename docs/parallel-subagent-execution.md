# Parallel Subagent Execution Pattern

## Overview

This pattern documents the optimal workflow for spawning specialized subagents using Laguna S 2.1 as the reasoning engine, with Hermes Agent managing task distribution and aggregation.

## Karpathy LLM Wiki Pattern Applied

### Core Principle: Specialized Workers
- **Hermes Agent** = Task Orchestrator (OS-level runtime)
- **Laguna S 2.1** = Reasoning Engine (1M token context)
- **Subagents** = Domain-specialized workers with dedicated contexts

### Parallel Execution Flow
```
┌─────────────────────────────────────────────────────────┐
│  Hermes Runtime (Orchestrator)                          │
│  ┌─────────────────────────────────────────────────────┐│
│  │  Laguna S 2.1 (Reasoning Engine - 1M context)     ││
│  │       │                    │                       ││
│  │   ┌─────────┐        ┌─────────┐                  ││
│  │   │Researcher│       │  Coder  │                  ││
│  │   │(Docs → md)│      │(scraper)│                  ││
│  │   └─────────┘        └─────────┘                  ││
│  │       │                    │                       ││
│  │       └──────┬───────────┬─┘                     ││
│  │              ▼           ▼                       ││
│  │         async_summary.md  scraper.py              ││
│  │                    │                             ││
│  │                    ▼                             ││
│  │           FINAL_REPORT.md (aggregation)         ││
│  └─────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────┘
```

## Implementation

### 1. Subagent Definition
Define specialized system prompts for each worker type:

```yaml
# ~/.hermes/subagents/coder.yaml
name: Coder
model: poolside/laguna-s-2.1
system_prompt: "You are a code generation and refactoring worker..."
tools: [file_editor, bash, python_runner]

# ~/.hermes/subagents/researcher.yaml  
name: Researcher
model: poolside/laguna-s-2.1
system_prompt: "You are a deep-dive research specialist..."
tools: [web_search, reader, file_editor]
```

### 2. Parallel Dispatch Command
```bash
hermes run --parallel \
  --agent Coder:"Fix all failing pytest units in ./src/utils.py" \
  --agent Researcher:"Analyze repository docs, summarize edge cases"
```

### 3. Live Transcript Monitoring
Each subagent streams progress to:
`~/.hermes/profile/cache/delegation/live/{deleg_id}/task-{n}.log`

## Best Practices

### Context Isolation
Each subagent gets:
- Dedicated workspace directory
- Isolated tool access
- Independent terminal session

### Error Handling
- Subagents raise `ValueError` for invalid URLs (not empty dict)
- File operations use `os.makedirs(exist_ok=True)`
- None inputs handled explicitly with type checks

### Type Conversion Heuristics
```python
# Boolean strings
if value.lower() == 'true': return True

# List detection (smart heuristic)
if ',' in value and not self._is_number(value.split(',')[0]):
    return [item.strip() for item in value.split(',')]
```
