## Overview

This guide documents how to set up an **automated LLM wiki** using the Hermes Agent CLI integrated with your Obsidian vault. Follow these steps to transform your [[wikilink]] personal note-taking system into a dynamic, AI-curated digital brain that [[wikilink]] continuously grows from raw inputs and session transcripts.

---

## Prerequisites

- **Obsidian**: Installed with [[community plugins]] enabled
- **Hermes Agent CLI**: Available via `hermes --version` (verify after installation)
- **Vault location**: Must point to your actual Obsidian vault root at `E:\tommy vault\tommy vault\Read & Write`

---

## Step 1: Install & Update Hermes Agent

Install the latest Hermes Agent CLI globally using pip:

```bash
# Install or update Hermes globally (uses Python 3.14.7 on your system)
pip install --upgrade hermes-agent

# Verify installation succeeded
hermes --version

# Expected output: hermes-cli version X.Y.Z
```

**Note**: On Windows, ensure you're using forward slashes in paths (`C:/` or `E:/`) to avoid MSYS path issues!

---

## Step 2: Configure Workspace Access

Point Hermes to your local Obsidian vault directory as its working directory:

```bash
# Set your active Obsidian Vault path (adjust if needed for Windows)
hermes config set workspace.path "E:/tommy vault/tommy vault/Read & Write"

# Allow full file write access within workspace
hermes config set workspace.allow_file_write true

# Verify configuration (optional)
hermes config list
```

**Security constraint**: Ensure [[restricted paths]] include `.private` folder to keep private notes inaccessible!

---

## Step 3: Install the `hermes-llm-wiki` Skill Kit

Install the wiki skill pack from the official repository or registry:

```bash
# Install the hermes-llm-wiki skill kit
hermes skills install hermes-llm-wiki

# Verify skill installation (should include hermes-llm-wiki in list)
hermes skills list

# Expected output includes "hermes-llm-wiki: Karpathy LLM Wiki pattern"
```

**Note**: Reload the `[[wikilink]] hermes-agent` skill if pruned to confirm installation!

---

## Step 4: Initialize Vault Folder Structure

Run the initialization command from within your vault directory:

```bash
# Navigate into your Obsidian vault root
cd "E:/tommy vault/tommy vault/Read & Write"

# Run structure initialization via Hermes CLI
hermes run "Initialize LLM Wiki structure in current directory"

# Or use specific heredoc pattern if needed:
hermes run <<-EOF | python
obsidian_wiki_init()
EOF
```

This creates the following [[wikilink]] target directories in your vault:

```text
E:\tommy vault\tommy vault\Read & Write/
├── Inbox/          # Raw clips, daily logs, conversation dumps
├── Raw/            # Unprocessed web saves, documents (from research)
├── _wiki/          # Compiled entity/concept pages generated by Hermes
└── Templates/      # Wiki compilation templates (YAML frontmatter examples)
```

**Note**: These directories may already exist from [[existing notes]] — the command ensures proper [[wikilink]] structure!

---

## Step 5: Configure `.hermes/config.json` for wiki Rules

Create your local config file inside your vault root (create `E:\tommy vault\tommy vault\Read & Write\.hermes\config.json`):

```json
{
  "skills": {
    "hermes-llm-wiki": {
      "enabled": true,
      "inbox_dir": "Inbox",
      "wiki_dir": "_wiki",
      "auto_link": true,
      "frontmatter": {
        "status": "compiled",
        "type": "concept"
      }
    }
  },
  "workspace": {
    "restricted_paths": [
      ".private",
      ".obsidian",
      ".git"
    ],
    "workspace_path": "E:/tommy vault/tommy vault/Read & Write"
  }
}
```

**Configuration notes**:
- `auto_link`: Automatically [[wikilink]] to existing notes when concepts are detected
- `restricted_paths`: Paths Hermes cannot access (`.private` keeps your private notes safe!)
- `frontmatter.status = "compiled"`: Marks Hermes-generated notes with structured frontmatter

---

## Step 6: Test Ingestion Workflow

Test by dropping a raw text file into `Inbox/` and triggering compilation:

```bash
# Create test note (example)
cd E:/tommy vault/tommy vault/Read & Write
echo "Machine learning basics: supervised vs unsupervised learning concepts" > Inbox/testing-concept.txt

# Compile it into the wiki directory
hermes run -i Inbox/testing-concept.txt -o _wiki --auto-link

# Or batch compile all unprocessed notes
hermes run "Compile all unindexed notes in Inbox into _wiki/ using [[wikilinks]]"
```

**Expected behavior**:
1. Hermes scans `Inbox/` for `.txt`, `.md`, or `.pdf` files
2. Uses `hermes-llm-wiki` skill to parse content → identify concepts
3. Creates structured note in `_wiki/concepts/<concept-name>.md` with YAML frontmatter
4. Auto-links to [[existing notes]] when same concepts detected elsewhere

## Best Practices

### For Daily Usage
- Drop raw research → unstructured notes [[wikilink]] into `Inbox/` each evening
- Run nightly compilation: `hermes run "Process all Inbox items"`
- Keep `_wiki/notes/` for compiled concepts, separate from `Inbox/` drafts

### For Security
- Ensure `.private` folder stays in `restricted_paths` config!
- Don't [[wikilink]] upload or share compiled notes from `_wiki/` containing sensitive data
- Review `auto_link` settings if you use [[wikilink]] external APIs (don't auto-link untrusted URLs)

### For Quality Control
- Use [`Templates/`] folder for YAML frontmatter templates: `concepts.md`, `projects.md`
- Periodically prune old notes in [`Inbox/`:] that weren't compiled after `>` 30 days
- [[wikilink]] Keep `_wiki/` separate from your regular note-taking (drafts) folders

## Troubleshooting Common Issues

### Issue 1: Permissions denied on `.private` folder
```bash
# Ensure .private is restricted in config.json:
hermes config set workspace.restricted_paths .private,.obsidian,.git
```

### Issue 2: Hermes can't find my Obsidian vault path
```bash
# Re-check workspace setting with Windows-compatible slashes:
hermes config set workspace.path "E:/tommy vault/tommy vault/Read & Write"
```

### Issue 3: Skill installation fails (deprecated)
```bash
# Verify skill list, reinstall if needed:
hermes skills install hermes-llm-wiki
hermes skills list | grep hermes-llm-wiki
```
