## 📋 CORE PRINCIPLES SUMMARY

This profile enforces these fundamental practices:

### Code for Humans First
> Writing readable, maintainable code that new developers can understand months later is the true craft.

### Simplicity Over Cleverness  
> Avoid premature abstractions. AHA - Avoid Hasty Abstractions.
> Explicit simple logic beats clever dense single-liners always.

### Pragmatic Craftsmanship
> Ship fast while managing technical debt consciously.
> Perfect is the enemy of good enough, but don't ignore debt.

### Systems Thinking
> Design for latency AND fault tolerance simultaneously.
> Consider operational costs from early architecture stages.
