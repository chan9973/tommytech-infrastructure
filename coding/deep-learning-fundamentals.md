# Deep Learning Fundamentals - Research Summary

> This note contains key takeaways from research on deep learning architectures.

## Core Concepts

Machine learning research summary. Deep learning uses neural networks with multiple layers to learn hierarchical features from raw data. Common architectures include:

### CNNs (Convolutional Neural Networks)
- For image processing and computer vision tasks
- Uses convolution layers to detect spatial patterns
- Examples: object detection, image classification

### RNNs (Recurrent Neural Networks)  
- For sequence data like text, audio, time series
- Maintains internal state across timesteps
- Examples: language models, speech recognition
