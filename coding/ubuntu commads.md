Here is a categorized list of the most essential Ubuntu terminal commands used for daily system operations, file management, and troub[[ubuntu commads]]leshooting.You can find a comprehensive reference guide on the official Ubuntu CLI Cheat Sheet.File Navigation & Directory Managementpwd: Prints the full path of your current working directory.
ls: Lists all visible files and folders in your current location.ls -la: Lists all items in long format, including permissions and hidden files.
cd [directory]: Changes your current location to the specified folder.cd ..: Moves your location up exactly one folder level.
mkdir [name]: Creates a brand new directory with your chosen name.File Operations & Text Editing
touch [filename]: Creates an empty file or updates an existing timestamp.
cp [source] [destination]: Copies a file or folder to a new location.
mv [source] [destination]: Moves or renames a specific file or folder.
rm [filename]: Permanently deletes a specific file from the filesystem.
rm -r [directory]: Deletes a non-empty folder and everything inside it.
cat [filename]: Outputs the entire content of a file onto your screen.
nano [filename]: Opens a simple, easy-to-use terminal text editor.
grep "[pattern]" [file]: Searches for specific text strings inside a designated file.System Administration & Information
sudo [command]: Runs any specified terminal command with administrative root privileges.lsb_release -a: Displays the specific version of Ubuntu installed on your machine.uname -a: Shows the running Linux kernel version and hardware architecture.df -h: Displays remaining disk space across all mounted drives cleanly.free -h: Displays total, used, and available system RAM capacity.top: Displays active system processes and real-time resource utilization.htop: Launches an interactive, colored resource monitor (requires installation).Package Management (Software Updates)sudo apt update: Refreshes your system's list of available software packages.sudo apt upgrade: Installs all available software updates safely.sudo apt install [package]: Downloads and installs a brand new software application.sudo apt remove [package]: Uninstalls a specified application but keeps configuration files.sudo apt autoremove: Purges orphaned software packages that are no longer required.Networking & Connectivityip addr: Displays your machine's local IP address and network interfaces.ping [host]: Tests network connectivity to a specific external server or website.wget [URL]: Downloads a specific file directly from an internet URL.curl [URL]: Sends or receives data across network protocols effortlessly.Are you trying to accomplish a specific task right now (like managing user permissions, configuring a network, or fixing an error)?
