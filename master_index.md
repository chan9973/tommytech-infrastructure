## 🏷️ Tag Conventions

Notes use YAML frontmatter tags for filtering in Obsidian:

```yaml
---
tags: 
  - cnc           # CNC machines, G-code
  - materials      # cutting parameters  
  - fusion360     # CAD/CAM software  
  - robotics      # AI + robot control  
  - python        # scripts, automation  
  - obsidian-hermes # integration docs
---
```

Use `Ctrl+P` → type `/tags` in Obsidian to filter by tag instantly!
